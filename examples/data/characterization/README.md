# Characterization example datasets

Same convention as `examples/EXAMPLE_DATA.md`: every file here is *synthetic*,
generated by running a real CADET-Process simulation (via
`examples/generate_characterization_example_data.py`) and adding noise. None
of it is measured data — no Lonza data of any kind is used anywhere in this
repository. Each file exists to exercise one `CharacterizationWidget` stage in
`examples/characterization.ipynb`, with a known "true" answer so a fit can be
checked against it, not just run without error.

All eight files share one base: `CharacterizationWorkbenchWidget()`'s own
default process (`InstrumentWidget` with "Use LC system" on and the periphery
units — `tubing_pre_injection`, `tubing_detectors`, `mixer` — included,
`Lumped Rate Model With Pores (LRMP)` column, `Steric Mass Action (SMA)`
binding). Each row below lists only what was changed from that, and which
`CharacterizationWidget` stage/settings it's meant for. All simulations run
100 minutes at the default 1/60 min sampling (6001 points); every file has a
`time_min,signal` header and reads directly with `DataImportWidget`.

| File | Stage | Changed from defaults | Noise (seed) |
|---|---|---|---|
| `periphery_pre_injection.csv` | `stage="periphery"`, `tubing_unit="tubing_pre_injection"` | `tubing_pre_injection.length = 0.35` (default `0.1`), `.axial_dispersion = 8e-7` (default `1e-7`) | Gaussian (scale 0.01), seed `20260924_01` |
| `periphery_detectors.csv` | `stage="periphery"`, `tubing_unit="tubing_detectors"` | `tubing_detectors.length = 0.22` (default `0.1`), `.axial_dispersion = 5e-7` (default `1e-7`) | Gaussian (scale 0.01), seed `20260924_02` |
| `pre_injection_mixer.csv` | `stage="pre_injection"` | `tubing_pre_injection.length = 0.35`, `mixer.init_liquid_volume = 3e-6` (default `1e-6`) | Gaussian (scale 0.01), seed `20260924_03` |
| `bed_replicate_0.csv`, `bed_replicate_1.csv` | `stage="bed"` (select both — a genuine joint 2-dataset fit, requires the **U-NSGA-III** optimizer, not Nelder-Mead) | `column.bed_porosity = 0.38` (default `0.72`), `.axial_dispersion = 6e-8` (default `1e-8`) | Gaussian (scale 0.015), seeds `20260924_04`/`_05` |
| `particles.csv` | `stage="particles"` | `column.film_diffusion = 2e-5` (default `1e-3`) | Gaussian (scale 0.015), seed `20260924_06` |
| `adsorption.csv` | `stage="adsorption"` (rapid equilibrium) | binding model set to `is_kinetic=False`, `characteristic_charge = 5.0`, `adsorption_rate = 2.0` (the equilibrium constant, in this mode), `desorption_rate = 1.0`, `capacity = 1200.0` (defaults: all zero — nothing binds at all) | Gaussian (scale 0.015), seed `20260924_07` |
| `capacity.csv` | `stage="capacity"` | Same binding setup as `adsorption.csv`, except `capacity = 900.0` | Gaussian (scale 0.015), seed `20260924_08` |

All noise is clipped at `0` afterward (no negative signal values). Signal is
sampled at the same location `CharacterizationWidget`'s own Preview defaults
to (`outlet`'s `inlet` port — the process outlet).

## Verified end-to-end

`bed_replicate_0.csv` + `bed_replicate_1.csv`, fit jointly through
`CharacterizationWidget("bed", ...)` with U-NSGA-III (population 12,
10 generations), starting from the LRMP column's own defaults
(`bed_porosity=0.72`, `axial_dispersion=1e-8`):

| Parameter | True value | Recovered |
|---|---|---|
| `bed_porosity` | 0.38 | 0.3797 |
| `axial_dispersion` | 6e-8 | 8.1e-8 |

`bed_porosity` recovers cleanly. `axial_dispersion` lands within the right
order of magnitude but not tightly (~35% high) at this population/generation
budget — a real identifiability characteristic of fitting both parameters
jointly off two noisy pulse traces (bed_porosity dominates retention time,
which the signal constrains strongly; axial_dispersion only shapes peak
spread, a weaker, noisier signal to fit against), not a bug. Matches the
same caveat `examples/EXAMPLE_DATA.md` already documents for its own
`axial_dispersion` case. A longer run (more generations, or a cleaner/
lower-noise reference) tightens it further; `bed_porosity` alone is the
reliable one to check quickly.

Re-run the check yourself: build the widget as in
`examples/characterization.ipynb`, select both `bed_replicate_*` datasets,
Preview, pick U-NSGA-III, Run, then compare `_runner._last_result.x_best`
against the true values above.

## Regenerating

```
python3 examples/generate_characterization_example_data.py
```

Deterministic (fixed seeds) — re-running produces byte-identical files.
